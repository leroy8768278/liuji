# 流迹

流迹是一个 macOS 原生 HTTP 调试代理。通过会话结构、时序和请求详情查看流经 Mac 或同一局域网手机的流量。项目采用 [MIT 许可证](LICENSE)，可以免费使用和修改。

## 运行

在 macOS 14 或更新版本上，可用 Xcode Command Line Tools 构建应用。

```sh
./scripts/build-app.sh
open 'dist/流迹.app'
```

脚本默认生成同时支持 Apple Silicon 和 Intel 的 `.app`。使用 `./scripts/build-app.sh --native` 可仅构建当前架构，也可以用 `swift build` 编译源码。

## 抓包

1. 要抓 Mac 上使用系统 HTTP/HTTPS 代理的流量，点击工具栏「Mac 抓包」。核对当前网络服务、两项系统代理和流迹端口，点击「开始 Mac 抓包」。macOS 可能会弹出网络设置授权。
2. 在 Safari 重新打开网页。在「加密」里展开主机和端口，选择一条 CONNECT 会话。明文 HTTP 可在请求和响应标签中查看内容。已有长连接可能需要重新建立。
3. 点击「恢复原系统代理」只结束系统接入。「停止监听」或正常退出也会尝试恢复。原来有其他 HTTP/HTTPS 代理时，会恢复原地址及启用状态。SOCKS 与系统绕过列表独立。启用 PAC 或自动发现时，可先使用单客户端接入。
4. 只调试指定客户端时，从「代理 → 代理设置」选择监听端口，点击「开启监听」，再把客户端 HTTP 代理设为 `127.0.0.1:8888`（或自定端口）。「开启监听」只启动流迹的本地服务。

**端口能连上，浏览器仍无会话。** 在「Mac 抓包」同时检查流迹端口与系统 HTTP、HTTPS 的生效地址。例如，流迹监听 8888 而系统仍指向 7897 时，普通浏览器流量会继续交给 7897。切换后再访问一个新页面。绕过列表内的地址、单独配置代理的客户端，以及抓包视图中被忽略或筛掉的请求都有不同的表现。

**沿用原来的本机上网代理。** 如果原先通过本机 HTTP 代理上网，可打开「代理 → 外部代理设置」，确认原服务的回环地址与端口（例如 `127.0.0.1:7897`），勾选后保存。系统 HTTP 和 HTTPS 指向流迹的监听端口（例如 8888），流迹再把外网请求交给 7897。本机服务及已配置的自有 HTTPS 源站走直连。上游需提供免认证的 HTTP 代理端口；流迹会在会话中显示上游连接或认证错误。

## 同网段手机接入

1. 将 Mac 和手机连到同一 Wi‑Fi 网络。在流迹顶部点击「手机接入」，选择 Mac 所在的局域网地址，填写手机的 Wi‑Fi IPv4 地址。
2. 点击「开启手机接入」。在手机的 Wi‑Fi 手动 HTTP 代理中填写面板显示的服务器、端口和本次生成的认证信息。有些 Android 客户端会在首次请求时询问认证信息。
3. 在支持该 HTTP 代理的手机应用中发起请求。明文 HTTP 可查看头部和正文，HTTPS 以 CONNECT 加密隧道显示。完成后关闭流迹的手机接入，并将手机的 Wi‑Fi 代理恢复到原设置。

手机接入单独监听选定的私有 IPv4 地址，使用独立端口，只接受配置的手机地址和本次凭据。

## 抓包范围

- 明文 HTTP/1.x 会话显示请求和响应内容，支持查看文本和 JSON。每段正文保留前 256 KiB 作为预览，代理照常转发剩余内容。
- 默认 HTTPS 通过 CONNECT 转发，可查看目标、耗时和双向传输量。对持有服务端身份文件的自有服务，macOS 15+ 还支持按主机和端口调试 HTTPS/HTTP 1.1。
- 默认监听本机回环地址。抓包会话保存在内存中，默认保留最近 500 条，可在录制设置中调整。
- 点击左下角的「查看示例会话」可以在启动代理前体验列表、筛选和详情。

## 代理工具

从菜单栏「工具」或主窗口「工具规则」打开面板。可以添加多条规则、逐条启停并一次保存。保存后，新请求使用最新规则，会话概览显示命中记录。

| 工具 | 用法 |
| --- | --- |
| 禁用缓存、阻止 Cookie | 按主机和路径控制本机开发 HTTP 流量的缓存标头和 Cookie。 |
| 远程映射 | 将本机 HTTP 开发地址转发到另一个回环后端。源路径支持精确匹配和 `/api/*` 形式的前缀匹配，保留查询参数。 |
| 本地映射 | 选择一个不超过 2 MiB 的本地文件，用于响应匹配路径的 `GET` 和 `HEAD` 请求。 |
| 改写 | 替换请求路径，或设置请求、响应中的 `X-Debug-` 标头。开发域名需先通过映射或域名覆盖连接本机。 |
| 域名覆盖 | 将 `.test` 或 `.localhost` 开发域名连接到 `127.0.0.1`，保留原主机名和端口。仅影响流经应用的明文 HTTP 请求。 |
| 黑名单 | 拦截精确主机或 `*.example.test` 匹配的子域名，返回 `403`。 |
| 白名单 | 启用后只允许匹配名单的主机。黑名单优先，空白名单会拦截所有请求。 |

映射和改写适用于回环地址及 `.test`、`.localhost` 开发域名的明文 HTTP。黑白名单也可控制新的 HTTPS CONNECT 隧道。普通 CONNECT 隧道内的内容保持加密。

## 浏览、保存与导出

- 结构视图在窗口左侧显示树，CONNECT 隧道归入「加密」分组，再按主机和端口展开；时序视图用于按请求时间浏览。
- 右键可复制 URL、查找会话、保存响应预览、导出单条会话、切换视图、排序、按主机筛选和创建规则。
- 通过「文件 → 保存会话」把当前工作区保存为 `.flowsession`。通过「打开会话」载入归档，并可从左下角返回实时抓包。最大归档大小为 128 MiB，每份最多 2,000 条记录。
- 「文件 → 新建会话」把后续记录放入新分组。点击「窗口 → 录制会话」回看旧分组，原连接结束时仍会更新原记录。
- 「编辑 → 在会话中查找」搜索整个工作区的 URL、标头和已保留的正文。可用 ⇧⌘G 与 ⌥⇧⌘G 在匹配请求间跳转。
- 「文件 → 导入 HAR」可打开 HAR 1.2，最多 128 MiB 和 2,000 条记录，每段正文最多保留 512 KiB。
- 「文件 → 导出 HAR」导出 HTTP 会话供其他分析工具读取。HAR 包含已捕获的 URL、头部及可导出的正文，CONNECT 会话保留在流迹归档中。

「代理」菜单可单独暂停录制，并设置转发延迟、每连接带宽和精确路径的本机 HTTP 请求断点。反向映射可将同一代理端口上的本机 HTTP 路径交给开发服务。端口转发在两个本机端口之间传送 TCP。

「工具 → 识别本机客户端进程」可为新的 Mac 回环连接记录进程名和 PID，在请求概览和右键菜单中查看。短连接可能在查询前结束，结果显示「未知」。

「工具」菜单支持规则方案及 `.flowrules` 文件的导入和导出。选好目录后，「自动保存会话」在暂停录制或停止代理时写入当前会话，「镜像本机响应」按指定的回环主机保存完整的 HTTP 响应正文。

## 右键调试

| 操作 | 生效范围 |
| --- | --- |
| 关注主机 | 多个关注主机列在结构树顶部，其余主机可在「其他主机」展开。时序视图可勾选只显示关注项。「显示 → 关注的主机」管理名单。 |
| 忽略录制 | 主机节点可忽略整个协议、主机和端口，明文请求节点可忽略该路径。已有记录保留，后续匹配请求仍会转发。在「代理 → 录制设置」管理或移除忽略项。 |
| 启用此服务的 HTTPS 调试 | 右键 HTTPS 会话或结构树中的主机，选择持有私钥且 SAN 包含此主机的服务端 PKCS#12。仅对配置的主机、端口和新连接生效；源站必须通过系统信任验证并提供相同叶证书。身份只在本次运行中使用。 |
| 添加断点 | 请求节点按协议、主机、端口、精确路径匹配，主机或 CONNECT 节点可匹配该服务的所有路径。设置里可选请求、响应或两个阶段。看到 HTTP 标头时才触发，普通加密隧道中的路径不可见。 |
| 断点命中 | 可展开查看标头、原样放行或中止。回环及已验证的自有服务可修改 `X-Debug-` 标头再放行。等待上限 60 秒，关闭全局断点会放行等待中的请求。 |

「文件 → 新建会话」保留上个录制分组，可从「窗口 → 录制会话」回看。支持导入、导出 HAR 1.2，以及全会话查找。概览中的请求进程识别可在「工具」显式开启。查看器映射、高亮规则和关注名单可在「显示」调整。
